PHASE 2: OCR & MRZ PARSER IMPLEMENTATION (IMMEDIATE NEXT STEP)
--------------------------------------------------------------------------------
1. Implement MRZ (Machine Readable Zone) Decoder:
   - Implement ICAO Doc 9303 standard for passports (Type 3) and ID cards (Type 1).
   - Compute and validate mathematical check digits (document number check digit,
     DOB check digit, expiration check digit, composite check digit).
   - If check digit fails -> instantly flag document as mathematically forged.

2. Implement DeepSeek OCR / Vision Model for Visual Inspection Zone (VIZ):
   - Extract raw text, dates, names, nationality, and document numbers.
   - Cross-Validate: Compare OCR text from VIZ against decoded MRZ fields.
     Any discrepancy (e.g. DOB on front does not match MRZ DOB) triggers a High-Risk Alert.


PHASE 3: DOCUMENT FORENSIC & TAMPER DETECTION ENGINE
--------------------------------------------------------------------------------
1. Error Level Analysis (ELA):
   - Detect compression artifacts and differences in JPEG compression rates
     caused by photoshopped text or spliced faces.
2. Font & Character Inconsistency Analysis:
   - Identify uneven font baselines, mismatched font weights, or irregular
     kerning in critical fields (DOB, Expiry, Passport No).
3. Stamp & Hologram Verification:
   - Feature matching (SIFT/ORB or Vision Transformer) to verify visa stamps
     against genuine ministry stamp templates.
4. Tamper Heatmap Generation:
   - Produce a visual heatmap highlighting suspicious regions on the document image
     for immigration officers to inspect in seconds.


PHASE 4: BIOMETRIC FACIAL VERIFICATION & ANTI-SPOOFING
--------------------------------------------------------------------------------
1. Portrait Extraction:
   - Automatically crop and normalize the portrait photo from the scanned document.
2. 1:1 Live Face Match:
   - Extract face embeddings (via FaceNet / InsightFace / ResNet) and compare with
     the live camera feed of the passenger.
3. Liveness / Anti-Spoofing:
   - Detect presentation attacks (e.g. holding a printed photo or smartphone screen).
4. 1:N Multi-Identity Search (Preventing Impersonation):
   - Query incoming face embeddings against a local vector database (FAISS/ChromaDB)
     to detect if the same person has previously traveled under a different name/passport.


PHASE 5: BACKEND API & MOCK BLACKLIST INTEGRATION
--------------------------------------------------------------------------------
1. Build FastAPI backend with endpoints:
   - POST /api/scan-document        : Uploads document image, runs OCR + MRZ + Forensics.
   - POST /api/verify-passenger     : Matches document photo against live webcam frame.
   - POST /api/check-blacklist      : Checks document ID against blacklisted / stolen database.
   - GET  /api/audit-report/{id}    : Generates downloadable forensic PDF / JSON report.
2. Implement Cryptographic Audit Logger:
   - Hash every verification event (SHA-256) into a tamper-proof sequential ledger.
